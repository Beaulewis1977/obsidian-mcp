**Test suites required (minimum 2 tests each — 1 success, 1 failure):**

1. **`describe('handleGetLinkGraph')`** [LINK-01]:
   - `it('should return graph with correct nodes, edges, and stats')` — setup mock vault, call handler with `{}` input, parse response JSON, assert:
     - `nodes` array has 4 entries
     - `edges` array includes edge from `note-a.md` to `note-b.md`
     - `edges` array includes an embed edge (type: 'embed') from note-a
     - `stats.total_nodes === 4`
     - `stats.total_edges` is correct count
     - `stats.orphan_count >= 1` (note-c has no links)
     - `isError` is undefined/falsy
   - `it('should return error for invalid vault')` — call with `{ vault: 'nonexistent' }`, assert `isError === true`

2. **`describe('handleFindOrphans')`** [LINK-02]:
   - `it('should identify fully orphaned notes (no incoming AND no outgoing)')` — setup mock vault, call with `{ type: 'full' }`, parse response, assert:
     - `orphans` array contains `note-c.md`
     - `orphans` array does NOT contain `note-a.md` or `note-b.md` (they have links)
     - `total >= 1`
   - `it('should filter by orphan type no_incoming')` — call with `{ type: 'no_incoming' }`, assert notes with no incoming links are returned
   - `it('should return error for invalid vault')` — call with invalid vault, assert `isError === true`

3. **`describe('handleSearchTags')`** [LINK-03]:
   - `it('should return all tags with usage counts')` — setup mock vault, call with `{}`, parse response, assert:
     - Tags include `recipe` with count >= 2 (note-a frontmatter + note-d frontmatter)
     - Tags include `cooking` with count >= 1
     - Tags include `healthy` (inline tag from note-a)
     - Tags include `orphan-tag` from note-c
     - Each tag entry has `notes` array listing note paths
   - `it('should filter tags by query')` — call with `{ query: 'rec' }`, assert only tags matching `rec` are returned (e.g., `recipe`)
   - `it('should return error for invalid vault')` — call with invalid vault, assert `isError === true`

4. **`describe('handleGetOutgoingLinks')`** [LINK-04]:
   - `it('should return outgoing wikilinks from a note')` — mock readNote for note-a, call with `{ path: 'note-a', include_embeds: true, resolve: false }`, parse response, assert:
     - `links` array has entries (wikilink to note-b + embed of image.png)
     - A link with `target: 'note-b'` and `type: 'wikilink'` exists
     - An embed with `target: 'image.png'` and `type: 'embed'` exists
   - `it('should exclude embeds when include_embeds is false')` — call with `include_embeds: false`, assert no embed entries
   - `it('should resolve link targets when resolve is true')` — mock noteExists to return true for note-b.md, call with `resolve: true`, assert links have `exists: true` or `exists: false`
   - `it('should handle aliased links correctly')` — mock readNote for note-b (has `[[note-a|my alias]]`), call handler, assert link has `target: 'note-a'` and `alias: 'my alias'`
   - `it('should return error for note not found')` — mock readNote to throw, call handler, assert `isError === true`

- Use `beforeEach(() => vi.clearAllMocks())` in each describe block
- Do NOT import or interact with rate limiter — link tools are read-only and rate limiting is handled at dispatch level
