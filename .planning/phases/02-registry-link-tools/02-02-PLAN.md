**Part A: Create `src/tools/link-graph.ts`**

This is the shared utility for wikilink parsing, inline tag extraction, and vault-wide graph building. Follow the research patterns exactly (Pattern 5, 6, 7 from 02-RESEARCH.md).

1. **`ParsedWikilink` interface:**
   ```typescript
   export interface ParsedWikilink {
     target: string;       // Base note name (no section, no alias)
     alias: string | null;
     section: string | null;
     isEmbed: boolean;     // true for ![[...]]
     raw: string;          // Full match text
   }
   ```

2. **`parseWikilinks(content: string): ParsedWikilink[]`** — regex-based parser using `/(!?)\[\[([^\]]+)\]\]/g`. Handles all 5 Obsidian formats: `[[Note]]`, `[[Note|Alias]]`, `[[Note#Section]]`, `[[Note#Section|Alias]]`, `![[embed]]`. Do NOT use remark-wiki-link (it does not parse pipe aliases or embeds correctly — confirmed bug, see research Pitfall 1).

   Parse logic: split inner on pipe first (alias), then hash (section). Guard for hash appearing before pipe. Return empty array for empty/null content.

3. **`extractInlineTags(content: string): string[]`** — extracts inline `#tag` patterns from markdown body. Regex: `/(?:^|[\s,;!?])(#[A-Za-z][A-Za-z0-9\/\-_]*)/gm`. Strip `#` prefix from output. Deduplicate. Does NOT exclude code blocks (documented acceptable tradeoff per research).

4. **`GraphNode` interface:**
   ```typescript
   export interface GraphNode {
     path: string;
     name: string;
     folder: string;
     outgoing: string[];
     incoming: string[];
     tags: string[];
   }
   ```

5. **`VaultGraph` interface:**
   ```typescript
   export interface VaultGraph {
     nodes: Map<string, GraphNode>;
     edges: Array<{ source: string; target: string; type: 'wikilink' | 'embed' }>;
   }
   ```

6. **`buildVaultGraph(vaultPath, listNotesFn, readNoteFn, options?)`** — single-pass vault walk that:
   - Calls `listNotesFn(vaultPath)` to get all notes
   - Sorts by path length ascending before building nameToPath (Pitfall 4: shortest path wins for same-name files)
   - Builds `nameToPath: Map<string, string>` for link target resolution (both basename and full relative path entries)
   - Initializes GraphNode for each note with empty outgoing/incoming/tags
   - First pass: for each node, calls `readNoteFn(vaultPath, notePath)`, extracts tags (frontmatter Array.isArray check + extractInlineTags), extracts wikilinks via parseWikilinks. Normalize frontmatter tags: strip leading `#` if present (Pitfall 5). Use sequential `for...of` with await (NOT Promise.all — Pitfall 3: avoid opening 1000 file handles simultaneously).
   - `resolveWikilink()` helper: tries `target + '.md'`, then `target`, then `path.basename(target)` against nameToPath. Returns null if unresolvable.
   - Second pass: fill `incoming` arrays from edges (reverse edges)
   - Wrap individual readNote calls in try/catch — log warning and skip notes that fail to read
   - Returns `VaultGraph`

Import `path` from Node built-in. Import `logger` from `../utils/logger.js`. Use `import type` for `Note` from `../types/index.js`. Do NOT import from `../filesystem/vault-reader.js` directly — accept functions as parameters (for testability, same as research Pattern 6).

**1. `handleGetLinkGraph(config, input)` [LINK-01]:**
- Get vault, call `buildVaultGraph(vault.path, listNotes, readNote)`
- If `input.folder` provided, pass folder-scoped `listNotes` call but resolve links against full vault nameToPath (Research Open Question 3 recommendation)
- Compute stats: `total_nodes`, `total_edges`, `orphan_count` (nodes with 0 incoming AND 0 outgoing), `avg_connections` (mean of incoming+outgoing per node), `most_connected` (top 10 by total connections)
- Build payload:
  ```typescript
  {
    vault: vault.name,
    stats: { total_nodes, total_edges, orphan_count, avg_connections, most_connected },
    nodes: Array.from(graph.nodes.values()).map(n => ({
      path: n.path, name: n.name, folder: n.folder,
      outgoing_count: n.outgoing.length, incoming_count: n.incoming.length, tags: n.tags
    })),
    edges: graph.edges
  }
  ```
- Return `{ content: [{ type: 'text', text: JSON.stringify(payload, null, 2) }], structuredContent: payload }`
- Wrap in try/catch, log errors, return createErrorResponse on failure

**2. `handleFindOrphans(config, input)` [LINK-02]:**
- Get vault, call `buildVaultGraph(vault.path, listNotes, readNote)`
- Filter nodes based on `input.type`:
  - `'full'`: no incoming AND no outgoing
  - `'no_outgoing'`: no outgoing (but may have incoming)
  - `'no_incoming'`: no incoming (but may have outgoing)
- Build payload:
  ```typescript
  {
    vault: vault.name,
    type: input.type,
    orphans: filteredNodes.map(n => ({ path: n.path, name: n.name, folder: n.folder, tags: n.tags })),
    total: filteredNodes.length,
    total_notes: graph.nodes.size
  }
  ```

**3. `handleSearchTags(config, input)` [LINK-03]:**
- Get vault, call `listNotes(vault.path)` to get all notes
- For each note, call `readNote(vault.path, notePath)`:
  - Extract frontmatter tags: `Array.isArray(note.frontmatter?.tags) ? note.frontmatter.tags : []`
  - Normalize: strip leading `#` if present, trim whitespace
  - Extract inline tags: `extractInlineTags(note.content)`
  - Merge both sets, track per-tag usage counts in a `Map<string, { count: number; notes: string[] }>`
- If `input.query` provided, filter tags that include the query string (case-insensitive)
- Sort by count descending
- Build payload:
  ```typescript
  {
    vault: vault.name,
    tags: Array.from(tagMap.entries()).map(([tag, info]) => ({ tag, count: info.count, notes: info.notes })),
    total: tagMap.size,
    ...(input.query ? { query: input.query } : {})
  }
  ```
- Use sequential `for...of` with await for note reads (same as graph builder — avoid opening too many file handles)

**4. `handleGetOutgoingLinks(config, input)` [LINK-04]:**
- Get vault, validate and ensure markdown extension on path
- Call `readNote(vault.path, notePath)`
- Call `parseWikilinks(note.content)` to get all outgoing links
- If `input.resolve` is true, check each link target's existence via `noteExists()`
- Filter based on `input.include_embeds` (exclude embeds if false)
- Count broken links (where `exists === false`)
- Build payload:
  ```typescript
  {
    source: notePath,
    links: filteredLinks.map(link => ({
      target: link.target, type: link.isEmbed ? 'embed' : 'wikilink',
      alias: link.alias, section: link.section,
      ...(input.resolve ? { exists: linkExistsResult } : {})
    })),
    total: filteredLinks.length,
    ...(input.resolve ? { broken_count: brokenCount } : {})
  }
  ```

All 4 handlers must include `structuredContent` alongside `content[0].text` (MCP 2025-11-25 spec compliance established in Phase 1).
