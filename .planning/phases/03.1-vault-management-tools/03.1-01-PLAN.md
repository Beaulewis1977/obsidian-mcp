  - Linux: `path.join(os.homedir(), '.config', 'obsidian', 'obsidian.json')`
- `readObsidianConfig(): Promise<ObsidianConfig>` — reads + JSON.parse; returns `{ vaults: {} }` on ENOENT; ensures `.vaults` key exists
- `writeObsidianConfig(config: ObsidianConfig): Promise<void>` — atomic write: create temp file in SAME directory (not os.tmpdir), then rename. `await fs.mkdir(dir, { recursive: true })` before write.

**2. Modify `src/config/index.ts`** — Add and export `getActiveConfigPath()`.

Add this function (after the existing `getConfigPaths()` private function):

```typescript
/**
 * Return the path of the config file currently in use.
 * Iterates getConfigPaths() and returns the first that exists on disk.
 * Returns null if running on defaults (no config file found).
 */
export async function getActiveConfigPath(): Promise<string | null> {
  for (const p of getConfigPaths()) {
    try {
      await fs.access(p);
      return p;
    } catch {
      // not found, try next
    }
  }
  return null;
}
```

This fixes the split-brain bug: vault handlers can now write to the correct config path instead of always writing to `~/.obsidian-mcp/config.json`.

**handleAddVault(config, args):**
1. Check vault name doesn't already exist in `config.vaults` (error if duplicate)
2. If `create_folder: true` and folder doesn't exist: `await fs.mkdir(args.path, { recursive: true })`. Track `folder_created: boolean`.
3. If folder exists and `create_folder: true`: `folder_created = false` (already existed).
4. Register in obsidian.json: `readObsidianConfig()`, generate ID via `randomBytes(8).toString('hex')`, add entry `{ path: pathForObsidian(args.path), ts: Date.now() }`, spread existing config to preserve unknown keys, `writeObsidianConfig()`. Set `obsidian_registered = true`.
5. Write to config.json: read active config path via `getActiveConfigPath()`. If null, use `path.join(os.homedir(), '.obsidian-mcp', 'config.json')` as fallback (create dir if needed). Build new VaultConfig entry: `{ name: args.name, path: normalizeVaultPathForPlatform(args.path), default: args.default, obsidian_api: args.obsidian_api ? { enabled: args.obsidian_api.enabled, url: args.obsidian_api.url, api_key: args.obsidian_api.api_key } : undefined }`. Read the current config file, parse as JSON, push new vault to `vaults` array. If `args.default`, unset `default: true` on all other vaults first. Write back. Set `mcp_registered = true`.
6. Hot-reload: `const reloaded = await loadConfig(); Object.assign(config, reloaded);`
7. Return success payload: `{ success: true, vault_name, path, folder_created, obsidian_registered, mcp_registered, note: "Restart Obsidian to see this vault in the vault switcher" }`
8. Wrap in try/catch, use `createErrorResponse('Failed to add vault', error.message, 'FILESYSTEM_ERROR', 'Check path validity and write permission.')`.

**handleRemoveVault(config, args):**
1. If `!args.confirm`: return error "Confirmation required" with VALIDATION_ERROR.
2. Find vault in `config.vaults` by name (case-sensitive match). Not found: error with VAULT_NOT_FOUND.
3. If `config.vaults.length === 1`: error "Cannot remove the last vault".
4. If vault `default === true`: error "Cannot remove the default vault — set another vault as default first using add_vault with default:true".
5. Remove from obsidian.json: `readObsidianConfig()`, find entry by comparing `normalizeVaultPathForPlatform(entry.path)` with `normalizeVaultPathForPlatform(vault.path)`, delete matching key, `writeObsidianConfig()`.
6. Remove from config.json: read active config path, parse, filter out vault by name, write back.
7. If `args.delete_folder === true`: `await fs.rm(vault.path, { recursive: true, force: true })`. Set `folder_deleted = true`.
8. Hot-reload: `Object.assign(config, await loadConfig())`.
9. Return payload: `{ success: true, vault_name, path, folder_deleted, obsidian_unregistered, mcp_unregistered }`.
10. Wrap in try/catch with `createErrorResponse()`.

**handleListVaults(config, args):**
1. Read obsidian config: `const obsConfig = await readObsidianConfig()`.
2. For each vault in `config.vaults`: build an info object:
   - `name`, `path`, `default` (boolean)
   - `exists_on_disk`: try `await fs.access(vault.path)` — true if no throw, false otherwise
   - `registered_in_obsidian`: check if any entry in `obsConfig.vaults` has a path matching `normalizeVaultPathForPlatform(vault.path)` (normalize both sides before comparing)
   - `note_count`: call `listNotes(vault.path)` and get `.length`. Use 0 on any error (vault not on disk).
   - `obsidian_api_enabled`: `vault.obsidian_api?.enabled ?? false`
3. Return payload: `{ vaults: [...], total: vaults.length }`.
4. Wrap in try/catch with `createErrorResponse()`.

**Critical patterns to follow:**
- Success response: `{ content: [{ type: 'text' as const, text: JSON.stringify(payload, null, 2) }], structuredContent: payload as Record<string, unknown> }`
- Error response: use `createErrorResponse()` — never construct isError manually.
- Path comparisons: ALWAYS use `normalizeVaultPathForPlatform()` on both sides.
- Import `os` for `os.homedir()` fallback in handleAddVault config path.
