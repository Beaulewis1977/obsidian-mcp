**Imports:**

import type { Server } from '@modelcontextprotocol/sdk/server/index.js';

**handleDiscoverTools(registry, config, args):**
- Signature: `export function handleDiscoverTools(registry: ToolRegistry, config: ServerConfig, args: z.infer<typeof DiscoverToolsSchema>): ToolResponse`
- Note: returns ToolResponse directly (synchronous), NOT Promise. The handler signature in ToolRegistration expects `Promise<ToolResponse>` but returning a plain value is valid since it auto-wraps.
- Extract `query` and `category` from args
- Map `registry.getAll()` to lightweight objects: `{ name: reg.definition.name, category: reg.category, description: reg.definition.description, enabled: registry.isEnabled(reg.definition.name) }`
- If `query` is provided, filter tools where `name.toLowerCase().includes(q)` OR `description.toLowerCase().includes(q)` (case-insensitive)
- If `category` is provided, filter tools where `category.toLowerCase() === category.toLowerCase()` (exact match, case-insensitive)
- Compute `categories` as sorted unique categories from ALL tools (not filtered): `[...new Set(registry.getAll().map(r => r.category))].sort()`
- Build payload: `{ tools, categories, total: registry.getAll().length, enabled_count: tools.filter(t => t.enabled).length }`
- Return: `{ content: [{ type: 'text' as const, text: JSON.stringify(payload, null, 2) }], structuredContent: payload as Record<string, unknown> }`

**handleEnableTool(registry, server, config, args):**
- Signature: `export function handleEnableTool(registry: ToolRegistry, server: Server | undefined, config: ServerConfig, args: z.infer<typeof EnableToolSchema>): ToolResponse`
- Note: `server` can be undefined (for tests or when server ref not available)
- Extract `tool_name` from args
- Look up registration: `const registration = registry.getRegistration(tool_name)`
- If not found, return `createErrorResponse('Tool not found', \`No tool registered with name: ${tool_name}\`, 'VALIDATION_ERROR', 'Call discover_tools to see available tool names.')`
- Check `const alreadyEnabled = registry.isEnabled(tool_name)`
- Call `registry.enable(tool_name)`
- Fire-and-forget notification (CRITICAL — do NOT await):
  ```typescript
  if (server) {
    void Promise.resolve()
      .then(() => server.sendToolListChanged())
      .catch(() => {}); // silence 'Not connected' in tests
  }
  ```
- Build payload: `{ enabled: [tool_name], already_enabled: alreadyEnabled, schema: registration.definition }`
  - `schema` field contains the FULL ToolDefinition (name, description, inputSchema, outputSchema, annotations) — this satisfies LAZY-05
- Return: `{ content: [{ type: 'text' as const, text: JSON.stringify(payload, null, 2) }], structuredContent: payload as Record<string, unknown> }`

**Important anti-patterns to avoid:**
- Do NOT await sendToolListChanged() — fire-and-forget only
- Do NOT call sendToolListChanged() without the `.catch(() => {})` wrapper
- Do NOT cache the enabled state at import time — always call `registry.isEnabled()` at handler invocation time
- Do NOT include `isError: true` on success responses
