**handleManageTags (XTND-01):**
- Validate: at least one of `add` or `remove` must be provided; if neither, return error.
- For each path in `args.paths` (sequential loop, not Promise.all):
  - Check noteExists. If not found, push `{ path, error: 'Note not found' }` to results (partial failure — do NOT abort).
  - Read note, compute currentTags (handle string or array from frontmatter).
  - Apply remove: filter out tags in args.remove.
  - Apply add: Set-dedup union with args.add.
  - Write note back if tags changed.
  - Push `{ path, tags_before, tags_after, tags_added, tags_removed, changed }` to results.
- Return `{ modified: results, total_modified: results.filter(r => r.changed).length }`.
- Only call createErrorResponse if vault not found.

**handleArchiveNote (XTND-02):**
- Get vault. Normalize source path with `ensureMarkdownExtension`.
- Check source exists with `noteExists`. Return error if missing.
- Compute archivePath: `path.join(args.archive_folder, path.basename(notePath))` — keep .md extension.
- Check archive collision: if `await noteExists(vault.path, archivePath)`, return error: "Archive target already exists at {archivePath}. Rename source or choose a different archive_folder."
- Move: `await fsMoveNote(vault.path + '/' + notePath, vault.path + '/' + archivePath)`. Note: `fsMoveNote` in vault-writer.ts takes absolute source/target paths. Construct as `path.join(vault.path, notePath)` and `path.join(vault.path, archivePath)`.
- If `args.add_date`, read note from new location, mutate frontmatter.archived_date = dayjs().format('YYYY-MM-DD'), write back.
- Return `{ success: true, original_path, archive_path: archivePath, archived_date: args.add_date ? date : undefined }`.

**handleExtractLinks (XTND-03):**
- Get vault, normalize path, check exists.
- Read raw content via `readNote`.
- Extract wikilinks/embeds using `parseWikilinks(note.content)`.
- Extract markdown links (e.g. `[text](https://...)`) using regex: `/\[([^\]]*)\]\((https?:\/\/[^\)]+)\)/g`.
- Extract bare external URLs (not already in markdown link) using regex: `/(?<!\()(https?:\/\/[^\s\)\"\'<>]+)/g`, applied line-by-line with line numbers.
- Collect: `{ wikilinks: [], embeds: [], markdown_links: [], external_urls: [] }`.
- Apply `args.types` filter if provided (omit arrays whose type is not in the filter).
- Return `{ path: notePath, wikilinks, embeds, markdown_links, external_urls, total: sum of all arrays }`.
- Line tracking: split content by '\n', iterate with index for markdown and external URL matches.
- For wikilinks/embeds: `parseWikilinks` does not return line numbers — that's acceptable; return them without line field or set line: null.

**handleGetWeeklyNote (XTND-04):**
- Get vault.
- Determine week string: `args.week ?? currentWeek()` where currentWeek uses `dayjs().format('YYYY-[W]WW')` — this avoids the dayjs isoWeek plugin (no plugin import needed; `YYYY-[W]WW` is purely format-based, not a parsed ISO week).
- Validate week format with regex `/^\d{4}-W\d{2}$/` — if invalid, return error.
- Filename = `dayjs` format of week string as provided: use the week string directly as filename since `date_format` defaults to `YYYY-[W]WW` and input already is in that format.
  - Actually: the filename should be derived from `args.date_format`. Since dayjs cannot parse `2026-W09` natively without plugins, use the week string as the filename stem directly: `filename = weekStr + '.md'` (ignore date_format in this simplified approach — the research recommends this simpler path).
- notePath = `path.join(args.week_folder, filename)`.
- If note exists, read and return it with `created: false`.
- If not exists and `create_if_missing=false`, return error.
- If not exists and `create_if_missing=true`, create folder if needed, call `writeNote` with empty content + frontmatter `{ week: weekStr }`, return `created: true`.
- Return `{ path: notePath, created, week: weekStr, frontmatter, content }`.

**handleListTemplates (XTND-05):**
- Get vault.
- Call `listNotes(vault.path, args.template_folder)` in a try/catch.
- If the folder does not exist (ENOENT error), return `{ templates: [], total: 0, note: "Template folder '${args.template_folder}' not found in vault" }` — NOT an error response.
- On success, return `{ templates: notes, total: notes.length, template_folder: args.template_folder }`.

All handlers: export as named async functions. Return type `Promise<ToolResponse>`.
